個人使用

個人方案與價格：入門、AI 部門、年約

個人使用是給一個人在用的人：一人公司、自由工作者、個人副業，或想先給自己裝一套的主管。裝在你自己的電腦、用你自己申請的 API Key，由台灣工程師遠端安裝。三階只差一件事——我們顧你多久：7 天、30 天，或一整年。

三題幫你選階

1. 你要 AI 幫你「回訊息、查資料、記住你」，還是「跑一整套固定流程」？
2. 裝好之後，你想自己維護，還是要有人顧一整年？
3. （選年約的人）一個 AI Agent、兩個 AI Agent，還是整個七部門交出去？

答完前兩題就有答案；選年約的再答第三題。

三階方案

Tier 1 · 支援 7 天

個人方案 1｜入門

個人方案 1 是官方原裝 AI 助理的遠端安裝服務，NT$999 單次付清，含 OpenClaw 或 Hermes 擇一、AnyDesk／DeskIn 遠端安裝、7 天技術諮詢。

給誰：第一次要一個常駐 LINE／Telegram 的 AI 助理、不想自己摸安裝的人。解決的是「教學看到一半放棄」。

OpenClaw 變體 A · 官方原裝技能單一 Agent NT$999 4 項原裝技能：搜尋、檔案、程式執行、瀏覽器；常駐 LINE 或 Telegram 看 OpenClaw 入門頁 →
Hermes 變體 B · 官方原裝基礎款，越用越聰明 NT$999 跨對話持久記憶、自我學習閉環；同價，擇一即可 看 Hermes 入門頁 →

無月費、無維運承諾；若因我方技術問題無法完成安裝，全額退費。

Tier 2 · 陪跑 30 天

個人方案 2｜AI 部門

個人方案 2 是讓 AI 工具組隊跑固定流程的部署服務，一個 AI Agent NT$6,000 或兩個 AI Agent NT$15,000 單次付清，含客製技能、跨 Agent 協作會議室、coding agent 串接與 30 天陪跑。

給誰：已在付 Claude Code／Codex 等 coding agent 訂閱、想讓工具組隊跑固定流程、願意自己維護的人。解決的是「自己當人肉轉接頭」——不是聊天機器人，是會自己跑的部門。

單 AI Agent 變體 A · 全 Agent 串接 NT$6,000 60 組客製技能＋跨 Agent 協作會議室＋coding agent 串接 看全 Agent 串接頁 →
雙 AI Agent 變體 B · 雙智能體 NT$15,000 OpenClaw＋Hermes 雙 AI Agent、全 Agent 串接、MCP 記憶互通；技能數依訪談 看雙智能體頁 →

AnyDesk／DeskIn 遠端安裝；無年度維運承諾。裝好後要人長期顧，看個人方案 3 或加購「系統健檢故障修復」。

Tier 3 · 顧一整年 · 主打

個人方案 3｜年約

個人方案 3 是有專屬工程師顧一整年的年約服務，一個 AI Agent NT$32,000、兩個 AI Agent NT$38,000、SUPERSOLO 七部門 NT$60,000，含一年維運陪跑（發現即修復）與 48 小時故障修復，次年續約 NT$30,000。

給誰：不想自己維護、要有人顧一整年的個人；頂規檔給一人公司想把七個部門交出去的人。解決的是「裝好一個月就晾著、壞了沒人理」。

單 AI Agent 副標：尊榮年約 NT$32,000／年 Hermes 或 OpenClaw 擇一、全客製、多智能體 MCP 互通；每週維護＋新增技能 看尊榮年約頁 →
雙 AI Agent 副標：年度旗艦 NT$38,000／年 Hermes × OpenClaw × Claude Code 多 Agent 架構、多部門覆蓋、CRM／雲端硬碟／Google Workspace 整合 看年度旗艦頁 →
SUPERSOLO 七部門 副標：超級個體 NT$60,000／年 一個人＝七個部門（內容自媒體、行銷、業務、客服、財務、行政、研發），一年每週維護 看 SUPERSOLO 頁 →

三檔皆不打折。流程：下單後先訪談確認需求與架構 → 安排遠端安裝 → 啟動年約。次年續約 NT$30,000／年（約 2,500／月），含每週維護＋48 小時故障修復。
