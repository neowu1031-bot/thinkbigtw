個人使用是給一個人在用的人：一人公司、自由工作者、個人副業，或想先給自己裝一套的主管。裝在你自己的電腦、用你自己申請的 API Key，由台灣工程師遠端安裝。依使用需求選擇：人格版 AI 助理含完整技能包＋7 天技術諮詢；雙 AI Agent 含協作會議室＋2 小時線上技術導覽；年約含一年維運。

個人方案需求評估

1. 你要 AI 幫你「回訊息、查資料、記住你」，還是「跑一整套固定流程」？
2. 裝好之後，你想自己維護，還是要有人顧一整年？
3. （選年約的人）一個 AI Agent，還是兩個 AI Agent？

答完前兩題就有答案；選年約的再答第三題。

三階方案

Tier 1 · 人格版 · 支援 7 天

個人方案 1｜人格版 AI 助理

個人方案 1 是人格版 AI 助理的遠端安裝服務，含 OpenClaw 或 Hermes 擇一、討好型或討伐型人格任選、完整個人技能包＋1 個客製小幫手、Coding Agent 串接 1–2 個、7 天技術諮詢，僅供個人使用。

給誰：第一次要一個有個性的個人 AI 助理、不想要通用平淡 AI 的人。解決的是「AI 用起來千篇一律、沒有自己的感覺」。

OpenClaw 人格版 變體 A · 討好型或討伐型人格，完整技能包 蝦皮賣場選購 討好型（溫暖支持，不盲目附和）或討伐型（直接犀利，不人身攻擊）；完整個人技能包＋1 客製小幫手＋Coding Agent 前往蝦皮下單 → Hermes 人格版 變體 B · 持久記憶加人格，越用越有個性 蝦皮賣場選購 跨對話持久記憶＋討好型或討伐型人格；同價，擇一即可 前往蝦皮下單 →

無月費、無維運承諾；僅供個人使用，不得用於營業或替客戶服務；若因我方技術問題無法完成安裝，全額退費。

Tier 2 · 雙 AI Agent · 兩種版本

個人方案 2｜雙 AI Agent

個人方案 2 提供兩種雙 AI Agent 選擇。共存版：OpenClaw＋Hermes 各自運作、各自記憶，人格組合自選，標準技能包，不含記憶互通與協作會議室，含 7 天技術諮詢。雙 AI Agent：兩邊 MCP 記憶互通、跨 Agent 協作會議室（此版本專屬）、技能數依訪談，含 2 小時線上技術導覽＋安裝後 7 天技術諮詢。

給誰：想同時裝兩個 AI 助理的人。先用共存版確認兩個 Agent 的分工，或直接上有記憶互通與協作會議室的雙 AI Agent 方案。

雙 AI Agent 共存版 兩個 Agent 各自運作、各自記憶 蝦皮賣場選購 OpenClaw＋Hermes 各自安裝、人格組合自選；標準個人技能包；7 天技術諮詢；不含記憶互通與協作會議室 諮詢此方案 → 雙 AI Agent 記憶互通＋跨 Agent 協作會議室 蝦皮賣場選購 OpenClaw＋Hermes MCP 記憶互通；跨 Agent 協作會議室（此版本專屬）；技能數依訪談；2 小時線上技術導覽＋安裝後 7 天技術諮詢 看雙 AI Agent 頁 →

AnyDesk／DeskIn 遠端安裝；無年度維運承諾。裝好後要人長期顧，看個人方案 3 或加購「系統健檢故障修復」。

Tier 3 · 顧一整年 · 主打

個人方案 3｜年約

個人方案 3 是有專屬工程師顧一整年的年約服務，含一年維運陪跑（發現即修復）與 48 小時故障修復，次年可選配續約含每週維護。個人年約方案請至蝦皮賣場選購。

給誰：不想自己維護、要有人顧一整年的個人；頂規檔給一人公司想把七個部門交出去的人。解決的是「裝好一個月就晾著、壞了沒人理」。

單 AI Agent 副標：尊榮年約 蝦皮賣場選購 Hermes 或 OpenClaw 擇一、全客製、多 AI Agent MCP 互通；每週維護＋新增技能 看尊榮年約頁 → 雙 AI Agent 副標：年度旗艦 蝦皮賣場選購 Hermes × OpenClaw × Claude Code 多 Agent 架構、多部門覆蓋、CRM／雲端硬碟／Google Workspace 整合 看年度旗艦頁 →

兩檔皆不打折。流程：下單後先訪談確認需求與架構 → 安排遠端安裝 → 啟動年約。次年可選配續約，費用依需求報價，含每週維護＋48 小時故障修復。
