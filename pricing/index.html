方案與價格

先從公司的工作，選導入方式。

Think BIG（大想成業有限公司）是總部位於台灣、服務全球的企業 AI Agent 導入商，以 TB FRAME（我們的四階段導入方法：評估、建置、驗證、維運）方法論協助企業把 AI Agent 部署在公司自己的設備上、資料留在公司內，並提供一年陪跑維運；我們扮演企業的遠端 FDE（Forward Deployed Engineer，前沿部署工程師）團隊：從聽懂需求、建置知識庫與 AI Agent、上線，到後續維運，一手包辦；另有個人 AI 助理安裝方案。

地端部署不等於所有連線都在本機。若使用雲端模型或外部服務，相關請求仍會送出；需要資料不出公司時，須確認本機模型、外連限制與可用功能。

企業導入優先，個人方案另有專區。

個人方案專區

個人使用

一個人在用：一人公司、自由工作者、個人副業，或公司主管想先給自己裝一套。裝在自己的電腦，用自己申請的 API Key。

個人方案請至蝦皮賣場選購，或預約需求訪談取得報價

  • 個人方案 1｜人格版 AI 助理：討好型或討伐型人格，完整技能包，支援 7 天
  • 個人方案 2｜雙 AI Agent：OpenClaw＋Hermes 協作，2 小時線上技術導覽＋安裝後 7 天技術諮詢
  • 個人方案 3｜年約：專屬工程師顧一整年，48 小時故障修復

不確定走哪扇門？三題幫你選

1. 用的人只有你一個嗎？
2. 資料能不能放在你自己的電腦跑？
3. 需要簽合約、要 SLA 嗎？

三題都答完，這裡會告訴你該走哪扇門。

個人方案 3｜年約與維護

裝好一個月就晾著、壞了沒人理，是 AI 助理最常見的死法。年約把「有人顧一整年」內建進去：發現即修復、48 小時故障修復、每週維護。兩檔：尊榮年約（單 AI Agent）與年度旗艦（雙 AI Agent），依需求報價。

客戶自理事項（所有個人方案共通）

  • AI 模型 API Key 自行申請（我方引導、不代辦），模型使用費依用量向原廠計費
  • LINE 僅支援官方帳號（Messaging API），個人帳號不可
  • coding agent（Claude Code／Codex 等）訂閱自備
  • Supabase 自行免費註冊
  • 安裝方式：AnyDesk／DeskIn 遠端連線；若因我方技術問題無法完成安裝，全額退費

※ 價格為我方服務費，不含第三方 AI 模型用量費。企業方案一律依需求訪談後報價，官網不顯示固定數字。
