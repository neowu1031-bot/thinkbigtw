方案與價格

先從公司的工作，選導入方式。

公司共用資料、跨部門工作與權限管理，從企業導入開始：先確認流程、資料與驗收，再討論配置及一年陪跑。只替自己安裝 AI 助理，請進個人方案專區。

企業導入優先，個人方案另有專區。

企業導入

企業使用

有員工、要多部門同時用、資料不能出公司，或需要合約 SLA 的公司。走需求訪談＋合約制，官網不顯示固定價。

洽詢報價 · 本地或雲端

  • 企業方案 2｜本地主權：資料不出公司
  • 導入流程：需求訪談 → 報價 → 合約 → 部署

個人方案專區

個人使用

一個人在用：一人公司、自由工作者、個人副業，或公司主管想先給自己裝一套。裝在自己的電腦，用自己申請的 API Key。

價格帶：NT$999 → 6,000／15,000 → 32,000／38,000／60,000

  • 個人方案 1｜入門：官方原裝，遠端裝好，支援 7 天
  • 個人方案 2｜AI 部門：工具組隊跑流程，陪跑 30 天
  • 個人方案 3｜年約：專屬工程師顧一整年，48 小時故障修復

不確定走哪扇門？三題幫你選

1. 用的人只有你一個嗎？
2. 資料能不能放在你自己的電腦跑？
3. 需要簽合約、要 SLA 嗎？

三題都答完，這裡會告訴你該走哪扇門。

個人方案 3｜年約與維護

裝好一個月就晾著、壞了沒人理，是 AI 助理最常見的死法。年約把「有人顧一整年」內建進去：發現即修復、48 小時故障修復、每週維護。三檔：一個 AI Agent NT$32,000、兩個 AI Agent NT$38,000、SUPERSOLO 七部門 NT$60,000；次年續約 NT$30,000。

客戶自理事項（所有個人方案共通）

  • AI 模型 API Key 自行申請（我方引導、不代辦），模型使用費依用量向原廠計費
  • LINE 僅支援官方帳號（Messaging API），個人帳號不可
  • coding agent（Claude Code／Codex 等）訂閱自備
  • Supabase 自行免費註冊
  • 安裝方式：AnyDesk／DeskIn 遠端連線；若因我方技術問題無法完成安裝，全額退費
