企業使用

企業方案：雲端上線，或本地主權

企業使用是給有員工、要多部門同時用、資料不能出公司，或需要合約 SLA 的公司。兩階都走需求訪談＋合約制、洽詢報價，官網不顯示固定價；差別只有一件事——資料放公司雲，還是留在公司內。

三題幫你選

1. 資料可以放在雲端（公司雲）嗎？
2. 要多快上線？
3. 還沒到部署規模、想先讓一個團隊試？

答完會告訴你先看哪一階。

兩階方案

Enterprise 1 · 雲端

企業方案 1｜雲端上線

企業方案 1 是企業雲端大模型 API 部署，給想快速上線、先讓多部門用起來的公司，解決「員工私下把資料貼公開 AI」——公司統一一套，低門檻快速上線。

  • 各部門專屬客製 Agent，部門間隔離、用量獨立監控
  • 員工白名單通道（Slack／Teams／LINE 官方帳號等）
  • 導入流程：需求訪談 → 報價 → 合約 → 部署
  • 支援期與 SLA：依合約

Enterprise 2 · 本地

企業方案 2｜本地主權

企業方案 2 是 B2B 本地大語言模型部署，資料不出公司，給法遵、機敏資料或內網環境的企業，解決的是「資料主權」。

  • 本地部署，模型與資料留在公司自己的機器
  • 異動前備份可回滾、依合約持續維護與技術支援
  • 導入流程：需求訪談 → 報價 → 合約 → 部署
  • 支援期與 SLA：依合約

導入怎麼走

1
需求訪談與部門盤點先聊哪些部門、哪些流程最痛、資料能不能出公司
2
建議與報價依訪談提出雲端或本地的架構建議與報價，導入時程依需求評估後告知
3
合約支援期、維護與 SLA 寫進合約
4
部署與驗收各部門客製 Agent 開發、資安框架導入、驗收測試，之後依合約維護
