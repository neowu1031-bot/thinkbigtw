OPENCLAW — AI AGENT OS

OpenClaw — AI Agent 的作業系統

OpenClaw 是一個開源的 AI Agent 平台，讓你在本機運行 客製化自動化技能（Skills）。不需要每次都開瀏覽器、不需要手動操作，OpenClaw 能自動執行排程任務、資料分析、檔案處理、API 串接等工作。安裝後透過終端機呼叫，24小時不停機。

客製化 Skills 本機執行 24h 不停機 MCP 支援 20+ 通訊平台
適合：想要本機 AI 自動化、重視資安的個人與企業。

03 — ADVANCED REASONING

Claude Managed Agent

CLAUDE MANAGED AGENT — ANTHROPIC

Claude Managed Agent — Anthropic 官方 AI Agent 框架

Claude Managed Agent 是 Anthropic 官方推出的 Agent 框架，讓 Claude 能夠自主規劃、執行多步驟任務。不只是問答，而是真正的「給任務、自動完成」。透過 Claude 的推理能力，Agent 能分析複雜情境、決定下一步行動、呼叫外部工具。

Anthropic 官方 多步驟推理 外部工具呼叫 MCP 原生支援
適合：需要高度推理能力、複雜決策自動化的進階用戶。

04 — THE PROTOCOL

任何 AI Agent，都能透過 MCP 串進同一套工作流程

Model Context Protocol — AI 工具的共同語言

MCP 是連接 AI Agent 與工具、資料的開放協議。Anthropic 於 2024 年提出並開源，2025 年 12 月將其捐贈給 Linux Foundation 旗下的 Agentic AI Foundation（AAIF）；協議的技術方向與日常運作仍由 MCP 維護者自主決定。

2024 開源公告 ↗AAIF 官方公告 ↗

Agent 可替換
用哪個 AI Agent 依需求選；支援 MCP，就能接入既有工作流程。
工具串一次，所有 Agent 共用
把工具接成 MCP 服務，完成相容設定與授權的 AI Agent 就能共用，減少重複串接。
權限與稽核集中在 MCP 這層管
在 MCP 串接層配置存取權限、操作紀錄與人工核准；這些治理能力需另外建置與設定。
這不只是裝幾個工具，而是一套能持續加入新 Agent 的 AI 自動化基礎設施。

個人 AI 助理常見問題

個人 AI 助理如何開始？

先確認設備、帳號與工作需求，再依支援範圍選擇個人方案；價格與服務條件請見個人方案專區。

地端部署代表資料不會離開電腦嗎？

地端部署不等於所有連線都在本機。若使用雲端模型或外部服務，相關請求仍會送出；需要資料不出公司時，須確認本機模型、外連限制與可用功能。

如何確認 AI Agent 的操作權限？

依工作所需配置資料與工具權限；對外發送、花費與正式系統變更，由指定負責人核准。
