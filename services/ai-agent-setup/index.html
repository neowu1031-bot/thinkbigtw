AI Agent Setup ／ AI Agent 搭建

AI Agent 搭建：把 AI 助理裝在你自己的電腦或公司主機上

AI Agent 搭建，是把能自己讀資料、照規則完成工作的 AI 助理，安裝到你的電腦、公司主機或公司名下的雲端主機上，並接到你平常用的 LINE、Telegram 或內部工具。Think BIG（大想成業有限公司）是台灣的 AI Agent 搭建與導入團隊，個人與企業都可以找我們，由台灣工程師遠端安裝。

用 LINE 說你的需求 先看哪一種適合我

01你是哪一種需求？

個人使用

想要一個 24 小時在線、會記事、會查資料的個人 AI 助理，接在你自己的 LINE 或 Telegram。

看個人方案個人 AI 助理搭建蝦皮賣場LINE 問

公司使用

想讓 AI 依公司文件回答、接 LINE 官方帳號回覆詢問，或整理內部流程。

2 分鐘需求表企業導入LINE 問

02我們會幫你做什麼

  • A確認需求，以及要接的通道（LINE、Telegram 或內部工具）。
  • B檢查設備規格：顯示卡型號、記憶體容量、作業系統。
  • C安裝 AI Agent 與模型（地端版或雲端輔助版）。
  • D接上 LINE、Telegram 或公司內部工具。
  • E設定權限：對外發送、涉及花費的動作，要由人核准才執行。
  • F用你的真實工作情境驗收。
  • G交付操作說明，並說明維護窗口。

04地端版和雲端輔助版差在哪

項目地端版雲端輔助版
模型在哪裡跑你的電腦或公司主機模型廠商的雲端服務
資料怎麼走模型與文件都在你的設備內處理問題與檢索到的文件段落，會送到模型廠商處理
模型用量費不另收依模型廠商用量另計
設備需求需要符合模型需求的顯示卡與記憶體一般電腦即可

地端部署不等於所有連線都在本機：用到外部服務（例如 LINE、網路搜尋）時，相關請求仍會送出。延伸閱讀：本地 AI 與公司資料。

05費用怎麼算

本頁不列價格。費用由下列幾項組成，報價前會逐項說明：

  • 01搭建服務費：依範圍確認（要接幾個通道、幾項工作、驗收條件）。
  • 02設備與第三方軟體：分開列，不混在服務費裡。
  • 03AI 模型用量費：地端版不另收；雲端輔助版依模型廠商用量另計，由你直接付給模型廠商。
  • 04LINE 官方帳號訊息費：接 LINE 官方帳號時，訊息費依 LINE 官方公告另計。

個人方案可在蝦皮賣場選購；企業依流程範圍與部署方式報價。

06安裝前要準備什麼

  • 01電腦或主機規格：顯示卡型號、記憶體容量。
  • 02要接的帳號：LINE 官方帳號或 Telegram（帳號由你本人申請、歸你所有）。
  • 03一件你最想先交給 AI 的工作。

不確定規格夠不夠？先看公司要跑本地大模型，需要什麼硬體，或直接用 LINE 傳規格給我們看。

07這些情況可能不適合

  • —需要 AI 自動對外回覆，而且不經人確認。
  • —文件大多是無法選取文字的掃描檔，又沒有時間整理。
  • —設備規格不足，又不考慮雲端輔助版。

遇到這些情況，我們會先說明可行的替代做法，再決定要不要開始。

08常見問題

AI Agent 搭建是什麼？

把能讀資料、照規則完成工作的 AI 助理，安裝到你的電腦、公司主機或公司名下的雲端主機，並接到 LINE、Telegram 或內部工具。搭建包含安裝、串接、權限設定與驗收。

AI Agent 搭建費用怎麼算？

費用由搭建服務費、設備、第三方軟體與 AI 模型用量費組成。地端版不另收模型用量費；雲端版依模型廠商用量另計。個人方案可在蝦皮賣場選購；企業依流程範圍與部署方式報價。

個人和企業的搭建有什麼不同？

個人搭建以一台電腦、一個 AI 助理為主，通常接 LINE 或 Telegram。企業搭建要先確認部門流程、資料來源、使用權限與驗收條件，再決定地端版或雲端輔助版。

一定要有很強的電腦嗎？

地端版需要符合模型需求的顯示卡與記憶體；規格不夠時可以改用雲端輔助版。安裝前工程師會先看你的設備規格再建議做法。硬體需求可以先看《公司要跑本地大模型，需要什麼硬體》。

資料會不會被送出去？

地端版的模型與文件在你的設備內處理；雲端輔助版會把問題與檢索到的文件段落送到模型廠商處理。用到外部服務時相關請求仍會送出，需要資料不出公司時，要一起確認本機模型與外連限制。

可以接 LINE 官方帳號當客服嗎？

可以把 AI Agent 接到 LINE 官方帳號，依你提供的文件回答詢問。建議對外回覆先由人確認再送出；LINE 官方帳號的訊息費依 LINE 官方公告另計。

遠端安裝怎麼進行？安全嗎？

由你在電腦上開啟遠端連線，工程師連線安裝，過程你看得到。請不要把密碼或 API Key 用訊息傳給我們；連線方式與結束後的處理會在安裝前說明。

要怎麼開始？

用 LINE 傳一兩句你想交給 AI 的工作，以及電腦或主機的規格。公司需求也可以填 2 分鐘需求表，由工程師確認範圍後回覆。
