# 花園背景三層素材

夢境花園 Hero 區的視差背景,共 3 張圖,**從遠到近、由不透明到透明**。

## 📋 上傳清單

| 檔名 | 內容 | 格式 | 是否透明 |
|---|---|---|---|
| `garden-back.jpg` | 後景 — 天空、雲、遠山、霧化遠景 | JPG | ❌ 不透明,滿版 |
| `garden-mid.png` | 中景 — 花叢、小溪、石徑、小樹 | PNG | ✅ 透明背景 |
| `garden-front.png` | 前景 — 近草、大花、蝴蝶、光斑 | PNG | ✅ 透明背景 |

## 📐 規格

- 比例:**16:9**(2560×1440 或更大)
- 中景/前景的**畫面中央 60%-70% 必須完全透明**(留給角色與文字)
- 三張風格鎖一致:同工具、同 seed、同 style reference
