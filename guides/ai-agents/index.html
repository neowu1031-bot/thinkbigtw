新 AI Agent 會不會取代龍蝦？各家 AI Agent 一次看懂

  • 大模型品牌推出的 AI Agent，費用綁訂閱方案的額度，適合有品牌生態綁定需求的協作任務。
  • 開源 AI Agent（如 OpenClaw、Hermes）可以自己選模型，按實際用量付費給模型商，適合長時間常駐與費用可控的情境。

一句話結論

每一個都很好。但如果要長時間運作、又想費用可控，大模型品牌推出的 AI Agent 就不會是首選，但很適合拿來協作。
  • 費用結構不同：訂閱型 AI Agent 費用固定含額度，額度用完就停；開源 AI Agent 依實際用量付費，可以預算導向地控制。
  • 適合的工作不同：訂閱型適合短時間協作、需要品牌生態（Gmail、Teams、WhatsApp）串接的任務；開源型適合 24 小時常駐、例行流程、費用可控的工作。
  • 可以一起用：常見做法是讓龍蝦（OpenClaw）或 Hermes 跑長時間例行任務，品牌 AI Agent 用來協作或做需要特定生態的任務。

先說清楚：AI Agent 是什麼

AI Agent 是依核准的資料、工具與操作範圍執行工作流程的 AI 助理；產物與重要操作仍需指定人員覆核。（完整術語表）

換句話說，AI Agent 不只是聊天機器人——它可以自己開瀏覽器、操作 App、在背景持續工作、依照排程執行任務。但「能不能幫你做事」，取決於它被賦予的工具範圍、模型能力，以及你的設定。

兩大類型

目前市面上的 AI Agent 可分成兩類：

  • 大模型品牌推出的 AI Agent：以訂閱方案使用，費用固定，額度用完需等重置或加購。例如 Claude、ChatGPT Agent、Gemini Spark、Grok Bot、Muse。
  • 開源 AI Agent（可自選模型）：軟體開源免費，模型費用依實際用量付給自選的模型商，或接本地大模型零模型費。例如 OpenClaw（龍蝦）、Hermes。

想長時間運作又控制費用，怎麼搭

三種常見情境，按你的工作性質選擇：

  1. 一個常駐 AI Agent 搭配你原本的訂閱：用 OpenClaw 或 Hermes 跑每天的例行工作（回訊息、整理、排程），你原本的品牌訂閱（Claude Pro、ChatGPT Plus 等）用來做需要協作或需要品牌生態的任務，不佔 24 小時額度。
  2. 兩個 AI Agent 分工：OpenClaw 和 Hermes 裝在同一台電腦，一個跑行動派工作（回訊息、流程），一個跑思考派工作（彙整、研究、寫稿）。→ 雙 AI Agent 方案
  3. 常駐 AI Agent 加上 coding agent 協作：龍蝦（OpenClaw）常駐跑例行任務，Claude Code 或 Codex 用來做程式、自動化腳本，透過協作會議室溝通。

常見問題

Q：2026 年常見的 AI Agent 有哪些？

分成兩類：大模型品牌推出、以訂閱方案使用的 AI Agent；以及開源、可自選模型的 AI Agent（如龍蝦）。各家介紹見本頁「2026 年常見的 AI Agent 有哪些」。

Q：新推出的 AI Agent 會取代龍蝦嗎？

兩者擅長的工作不同，可以一起用。每一個都很好。但如果要長時間運作、又想費用可控，大模型品牌推出的 AI Agent 就不會是首選，但很適合拿來協作。

Q：龍蝦 AI 是什麼？要錢嗎？

龍蝦是台灣使用者對開源 AI Agent 的暱稱。軟體本身開源免費；使用時要付 AI 模型用量費，依用量計算，由使用者直接付給模型商；找人安裝另外收服務費。→ 龍蝦代裝服務說明

Q：訂閱制 AI 的額度用完怎麼辦？

等官方額度重置、升級方案、改用依用量計費的 API，或把常駐工作交給自選模型的 AI Agent（如龍蝦），品牌 AI Agent 留給需要協作的時段。

Q：想讓 AI Agent 長時間運作，費用怎麼控制？

選能自己換模型、依用量付費的做法，並設定用量上限；需要協作的時段再搭配訂閱型 AI Agent。龍蝦等開源 AI Agent 都支援自選模型。

Q：品牌 AI Agent 和龍蝦可以一起用嗎？

可以。常見做法是龍蝦負責常駐和例行工作，品牌 AI Agent 負責需要協作的任務。→ 龍蝦＋coding agent 協作 / 雙 AI Agent 方案

Q：自己安裝 AI Agent 安全嗎？

關鍵在最小權限、本機部署，以及不裝來路不明的技能。詳細說明→ 龍蝦安全指南

Q：Think BIG 的方案包含 AI 模型費用嗎？

不含。方案價格是安裝與設定的服務費；第三方 AI 模型用量費依實際用量計算，由你自行負擔。詳見 常見問題。
