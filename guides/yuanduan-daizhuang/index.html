會搜「找人遠端幫忙安裝 OpenClaw」的人，通常卡在兩件事：一是自己裝不起來，二是不放心讓陌生人連進自己的電腦。前者好解決，付錢請會的人裝就好；後者才是真正的門檻——你要把螢幕交給一個沒見過面的工程師，憑什麼信他？

這篇不談 OpenClaw 好不好用（那在上一篇代裝拆解講過了），只談「遠端代裝」這件事本身：流程長怎樣、連線期間你會看到什麼、哪些事我們明確不做，以及不管你最後找誰裝，都應該拿去檢查對方的五個問題。

「遠端代裝」是什麼？跟看教學自己裝差在哪

遠端代裝的意思很直白：工程師透過遠端桌面軟體連進你的電腦，把 OpenClaw 整套裝好、串好、確認能用，你在螢幕前看著全程。你不用碰終端機，也不用查英文錯誤訊息。

跟自己照教學裝比，差最多的是工程師手上的「判斷」。教學只能寫一條理想路徑，但每台電腦的系統版本、權限設定、已裝軟體都不同，裝到一半跳出的錯誤，教學裡多半查不到。代裝服務付的錢，一大半是買工程師處理這些岔路的經驗。

而「顧問服務」是代裝的延伸：裝好只是起點，你的工作流程要怎麼交給 AI 助理、需要哪些技能、費用怎麼控，這些是安裝之後才開始的問題。我們的做法是先談需求再談規格，談清楚了才收錢。

完整流程：從下單到裝好，你會經歷什麼

  1. 下單前先聊：告訴我們你的電腦環境（作業系統、大概的規格）跟你想拿 AI 助理做什麼。環境不合適，我們會先講，不會讓你下了單才發現裝不了。
  2. 下單、約時間：入門款在蝦皮下單，工程師依訂單聯繫，約一個雙方都方便的時段。服務時間是週一至週五 10:00–00:00。
  3. 建立遠端連線：時間到了，你開啟 AnyDesk 或 DeskIn，把連線代碼給工程師。連線是由你這端允許才建立的，你隨時可以中斷。
  4. 安裝過程全程可視：工程師的每一步操作都在你的螢幕上進行，你看得到他開了什麼、改了什麼。需要你輸入帳號或授權的地方，由你自己動手，工程師只在旁邊引導。
  5. 當場驗收：裝完一起確認 AI 助理跑得起來、答得出話、串接的通訊軟體收得到訊息，才算完成。
  6. 裝完立即斷線：安裝完成後遠端連線立即斷開，電腦裡不留任何遠端存取的後門程式。之後有問題，是你主動聯繫我們，不是我們還連得進來。

裝完後有安裝後 7 天技術諮詢，入門款也含一段線上導覽，教你基本操作。

資安與信任：我們明確不做的事

找人遠端連進電腦，該擔心的不是「他會不會裝錯」，是「他還做了什麼」。所以與其講我們多可靠，不如把「不做的事」白紙黑字列出來，你之後也可以拿這份清單驗證：

  • 不要求你提供任何帳號密碼。需要登入的地方由你自己輸入，密碼、金鑰一律不透過 LINE 或任何聊天訊息傳遞。
  • 不代申請、不代管你的 API Key。AI 模型的金鑰由你自己申請，工程師口頭引導流程，但金鑰是你的，只寫進你電腦裡的系統設定檔，不經手、不留存。
  • 金鑰不上傳雲端版控。安裝過程不會把你的任何憑證推到雲端版本控制系統。
  • 只用 AnyDesk 或 DeskIn。不接受其他遠端軟體、不用 SSH 直連、不到府安裝。堅持只用這兩款，是因為連線由你允許、過程你全程看得到、紀錄可追溯。
  • 只裝官方原版。OpenClaw 用官方原始碼安裝，不用來路不明的第三方轉載版本。
  • 裝完斷線，不留後門。上面講過，值得再講一次。

以上全是所有方案共通的基本作法，不另外加價。如果你需要供應鏈掃描、24 小時監控這類企業級資安機制，那屬於客製方案的範圍，可以另外聊。

怎麼挑遠端代裝服務？五個檢查點

這段不是只寫給要找我們的人。市面上提供 OpenClaw 安裝的服務不只一家，不管你最後找誰，建議都先問對方這五個問題：

  1. 用什麼工具連線？ 答案應該是具名的主流遠端桌面軟體（如 AnyDesk、DeskIn），而且連線由你允許、你可中斷。如果對方要你交出 SSH 帳號或裝來路不明的連線程式，換一家。
  2. 會不會跟你要密碼或金鑰？ 正規做法是你自己輸入、金鑰只落在你的電腦。任何要你把密碼貼到聊天室的，直接淘汰。
  3. 裝完之後對方還連得進你的電腦嗎？ 答案應該是「不能，除非你下次再允許」。問清楚有沒有留常駐的遠端存取。
  4. 費用結構講清楚了嗎？ 重點是「服務費」跟「AI 模型用量費」有沒有分開講。模型費依用量計、由你自付，這件事如果對方不主動講，其他話也要打折聽。
  5. 裝的是不是官方原版？ 問一句「裝的版本來源是哪裡」，答不出來或含糊帶過的，風險自負。

我們自己就是照這五條做的，所以敢把它寫成公開的檢查清單。你拿去問任何一家都成立。

費用怎麼算？兩筆錢，分開記

遠端代裝的費用結構就兩筆，講清楚就不會有事後的不愉快：

  • 服務費：付給我們的錢，一次付清，不收月租或訂閱費。OpenClaw 官方原裝入門款是 NT$999，含環境建置、官方原裝技能、AI 模型串接（擇一）、通訊平台串接（擇一）、線上導覽與安裝後 7 天技術諮詢。
  • AI 模型用量費：付給模型原廠的錢（例如 Claude、ChatGPT、Gemini 的 API 費用），依你的實際用量計費、由你自行負擔，跟我們無關，也不含在 999 裡。

之後想加功能，是加購制：客製技能包分 10 組（NT$1,000）、20 組（NT$2,000）、40 組（NT$3,000）三種規格，下單前由工程師依你的目標評估需要幾個技能，再對應規格購買，避免買了不夠用或超買浪費。

如果因為我方技術問題導致無法完成安裝，全額退費，並依消費者保護法相關規定辦理。

裝完之後：顧問服務接手的部分

代裝解決「裝不起來」，顧問服務解決「裝完不知道怎麼用得深」。常見的走法是：

  • 先用官方原裝技能跑一陣子，弄清楚自己每天真正重複在做的事是什麼。
  • 需求浮出來之後加購技能包，讓工程師把你的具體流程（自動回信、報價單、排程提醒之類）做成專屬技能。
  • 不想自己維護的，再考慮年約方案，由工程師持續陪跑、更新與維護。

順序是需求先、規格後。我們不建議一開始就買到頂，先把 999 用出心得，錢才花在刀口上。

常見問題 FAQ

Q：完全不懂程式，可以找人遠端幫忙安裝 OpenClaw 嗎？

A：可以，這正是遠端代裝服務的對象。工程師透過 AnyDesk 或 DeskIn 遠端安裝，你不需要任何技術背景，只要開電腦、允許連線、在需要授權時自己操作一下。

Q：讓工程師遠端連進我的電腦，安全嗎？

A：連線由你這端允許才建立、你隨時可中斷、全程操作都在你的螢幕上、裝完立即斷線不留後門。我們也不會向你索取任何帳號密碼——需要登入的地方由你自己輸入。詳見上面「我們明確不做的事」那段。

Q：遠端代裝要多少錢？之後還有月費嗎？

A：OpenClaw 官方原裝入門款服務費 NT$999，一次付清，我方不收月租。但 AI 模型的 API 用量費依實際使用量由你自付，這是付給模型原廠的錢，跟服務費是兩回事。

Q：可以到府安裝或用 SSH 讓你們直接連嗎？

A：都不行。本服務僅透過 AnyDesk 或 DeskIn 遠端連線安裝，不接受其他遠端方式（含 SSH）、不進行線下交易。限縮連線方式是為了讓整個過程透明、可追溯。

Q：API Key 可以請你們幫我申請嗎？

A：不代申請、不代管。API Key 需由你自行申請，工程師會口頭引導流程。金鑰只寫入你電腦裡的設定檔，不透過聊天訊息傳遞，也不會上傳到任何雲端版控。

Q：想接 LINE，有什麼限制？

A：LINE 串接僅支援 LINE 官方帳號（Messaging API），個人 LINE 帳號無法串接。官方帳號申請免費，工程師會引導你完成。

Q：安裝當天我需要準備什麼？

A：一台符合基本規格、能上網的電腦，裝好 AnyDesk 或 DeskIn，加上你要串接的服務帳號（需要時你自己登入）。下單前的聊聊階段會先跟你確認環境，不會當天才發現缺東西。

Q：裝完出問題怎麼辦？你們還連得進來嗎？

A：連不進來，這是設計好的——裝完即斷線。安裝後 7 天內有技術諮詢，你主動聯繫我們，需要再次遠端時，也是由你重新允許連線才會建立。

Q：如果裝不起來會退錢嗎？

A：若因我方技術問題無法完成安裝，全額退費。服務依消費者保護法相關規定辦理。

結論：把信任建立在「可驗證」上

找人遠端幫忙安裝 OpenClaw，說到底是一次信任交易。我們的答案不是「相信我們」，而是把流程跟界線寫成你可以逐條驗證的清單：連線你允許、操作你看得到、密碼你自己輸、裝完就斷線、費用分兩筆講明白。

你可以拿這套標準來檢查我們，也可以拿去檢查任何一家。通過檢查的服務才值得把螢幕交出去。
