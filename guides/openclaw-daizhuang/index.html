什麼是 OpenClaw？什麼又是「OpenClaw 代裝」？

OpenClaw 是一套可以在你自己電腦上跑的 AI 助理（AI Agent）框架。跟一般聊天機器人不同的地方在於：它不是只會回你話，而是能實際「動手」，幫你整理檔案、回訊息、跑固定流程、串接你在用的工具。

聽起來很好，問題在安裝。要讓它跑起來，中間有一段對非工程師不太友善的設定過程：環境要對、權限要開、各種服務要串。裝錯一個環節，它就是不動，而錯誤訊息還是英文。

所以就有了 OpenClaw 安裝服務，也就是俗稱的「代裝」：你不用碰那些指令，由工程師遠端幫你把整套裝好、跑起來、確認能用，你只要在旁邊看著。AI 助理安裝這件事，本來就不該是你一個人對著螢幕硬扛。

999 入門款到底幫你裝什麼？逐項拆解

這是大家最想知道的一段。我們把 999 入門款拆開，讓你看清楚每一塊：

1. OpenClaw 官方原裝，一個 Agent

裝的是 OpenClaw 官方原本釋出的版本，不是魔改、不是山寨。一個 Agent 的意思是：你有一個專屬的 AI 助理實例，跑在你自己的機器上。

2. 本機部署，資料在你自己電腦

入門款是裝在你自己的電腦裡，不是丟到不知道哪裡的雲端。對很多人來說，「東西在自己手上」這件事本身就值得。

3. 台灣工程師遠端安裝

由台灣工程師透過 AnyDesk 或 DeskIn 遠端連線幫你裝。全程中文溝通，看得到工程師在做什麼。裝到能跑、確認可用，才算交付。

4. 官方原裝技能

入門款帶的是 OpenClaw 官方原裝的基礎能力。想要更多、更貼你工作場景的技能，可以另外加購技能包（後面會講）。

一句話總結：999 買的是一個裝好、能跑、在你自己電腦上的 OpenClaw AI 助理，加上台灣工程師遠端幫你裝到好的服務。它不是一份要你自己照著做的教學文件。

代裝流程長怎樣？你要做的其實很少

很多人以為代裝很麻煩，實際上你的部分很輕鬆：

  1. 下單：在蝦皮完成入門款下單。
  2. 約時間：工程師依訂單跟你聯繫，約一個雙方方便的安裝時段。
  3. 遠端連線：到了時間，工程師用 AnyDesk／DeskIn 連進你的電腦。
  4. 你泡杯咖啡看著：這一段幾乎都是工程師在操作。你只要在旁邊，需要你確認帳號或授權時點一下。
  5. 確認能用：裝完當場一起確認 AI 助理跑得起來、答得出話，才結束。

真的，你的工作量大概就是「開電腦、允許遠端、看著」。這也是代裝存在的意義，把難的部分留給會的人。

誠實時間：哪些要你自己準備？

這段我們一定講清楚，因為看到有人裝完才發現「還要另外弄這些」，那種感覺很差。以下是入門款不含、需要你這邊配合的部分：

  • AI 模型的 API Key：AI 助理背後要接一個大語言模型才會思考。這個模型的帳號（API Key）需要你自己申請，工程師會引導你怎麼弄，但不代你申請。
  • 模型的使用費用：AI 模型是依用量計費的，這筆錢由你依實際用量自付，不包含在 999 裡。用得多付得多，用得少就少。這跟代裝服務費是兩回事。
  • LINE 串接只支援官方帳號：如果你想把 AI 助理接到 LINE，只能用 LINE 官方帳號（Messaging API），個人 LINE 帳號沒辦法。官方帳號可以免費申請，工程師會引導。
  • 部分外部服務要自己免費註冊：某些進階串接會用到第三方服務（例如免費的資料庫服務），需要你自己註冊一個免費帳號。
我們寧可先講白，也不要你事後覺得被埋伏。服務費一次付清，模型用量費另計。這就是入門款的費用結構，記住這兩句就對了。

裝好之後，你能拿它做什麼？

裝好只是起點。OpenClaw 入門款讓你有一個能動手的 AI 助理，實際用途看你的工作長怎樣，常見的像是：

  • 把每天重複、無腦但花時間的雜事交給它。
  • 讓它照你設定的流程，固定時間做固定的事。
  • 你講人話，它幫你把事情往前推，而不是丟一串你還要自己消化的資訊。

想要它更懂你的工作、會的招式更多，就是靠加購技能，這也是入門款的設計邏輯：先用 999 把底裝好，再依需求長出去。

想升級？入門款之後的路

999 入門款是階梯的第一階，刻意做得好進入。之後你可以視需求往上：

  • 技能包加購：想要更多技能，可以加購技能包，分成 10 組、20 組、40 組三個級距（NT$1,000／2,000／3,000）。這些技能走「省 Token」的設計思路，讓每次呼叫更划算。
  • 多 Agent 協作：如果你要的是多個 AI 助理分工、串接更多工具的架構，上面還有更完整的方案。這些屬於客製範圍，會依你的需求先聊再報。

不用一次到位。先把入門款用起來，知道自己真正需要什麼，再加。這樣的錢花得最清楚。

不想用了怎麼辦？

也一起講。OpenClaw 若之後你不想留了，有對應的卸載服務（NT$500），由工程師遠端幫你乾淨移除，不會留一堆殘檔在你電腦裡。用得舒服是你的自由，不用了要收乾淨也是我們的事。

常見問題 FAQ

Q：完全不懂程式，也能裝 OpenClaw 嗎？

可以。這正是代裝服務存在的原因。工程師全程 AnyDesk／DeskIn 遠端幫你裝，你只要開電腦、允許連線、在旁邊看著就好，遇到需要你授權的地方點一下即可。

Q：OpenClaw 代裝要多少錢？

入門款服務費 NT$999，一次付清。要特別注意的是：AI 模型的 API 使用費是依你的實際用量另計、由你自付，不含在 999 裡。這是兩筆不同的錢，我們會事先講清楚。

Q：999 入門款和更高階的方案差在哪？

入門款是 OpenClaw 官方原裝技能、單一 Agent、本機部署。更高階的方案會有更多客製技能、多個 Agent 協作、串接更多工具的架構。簡單說：入門款是「先能跑」，高階是「跑得更複雜、更貼你的工作」。

Q：資料會不會被上傳到雲端？

入門款是本機部署，AI 助理跑在你自己的電腦上。至於接哪個 AI 模型、資料怎麼流動，會依你選的模型與設定而定，這部分安裝時會跟你說明，不誇大也不含糊。

Q：安裝要花多久？我要一直守著嗎？

一般入門款的遠端安裝就是一個時段內完成，中間主要是工程師在操作。你不用全程盯著螢幕，但建議人在旁邊，方便在需要授權或確認時處理一下。

Q：可以接到我的 LINE 嗎？

可以，但只支援 LINE 官方帳號（Messaging API），個人 LINE 帳號不行。官方帳號免費申請，工程師會引導你完成。

Q：裝完發現不能用，會退錢嗎？

如果是因為我方的技術問題導致無法完成安裝，全額退費。服務終止依消費者保護法辦理。

Q：AnyDesk 遠端安全嗎？

AnyDesk／DeskIn 是遠端桌面工具，連線由你這端允許才建立、你也能隨時中斷。整個安裝過程你都看得到工程師在做什麼。我們不會、也不需要向你索取任何帳號密碼——金鑰、密碼一律不透過聊天傳遞。

結論：這 999 到底該不該花？

如果你的情況是「想用 OpenClaw、但一看到安裝步驟就投降」，那代裝服務就是為你設計的。你付的不只是把軟體裝起來，更是省下自己摸索半天還不一定成功的時間，換一個當場能用的 AI 助理。

如果你本來就會自己裝，那你可能不需要這個服務——這也沒關係，我們不會硬跟你說一定要花這筆錢。工具而已，適合才用。

準備好了嗎？

OpenClaw 入門款在蝦皮直接下單，工程師依訂單聯繫約安裝時間。從「想用但不會裝」到「今天就有自己的 AI 助理」。
