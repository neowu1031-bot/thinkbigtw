Think BIG 的 Hermes 與 OpenClaw 比較：差別、怎麼選、誰適合哪一個

OpenClaw 跟 Think BIG 自己養的 Hermes 到底差在哪？一個人、一家公司、不同工作場景怎麼挑？這篇用白話講清楚定位、記憶方式、技能生態、適合誰，附上 Think BIG 五級方案哪一級帶哪個工具的對照表。

發布：2026-09-13

如果你搜「Hermes vs OpenClaw」進來，應該會看到兩種完全不同的東西：一邊是研究、開源、長對話的研究型助理；一邊是裝在你電腦、能把事做掉的工具型助理。講白話：

  • OpenClaw 是裝在你電腦上、能把事做掉的助理——看訊息、整理檔案、跑固定流程、串你正在用的工具。
  • Think BIG 養的 Hermes 是同一個家族的第二個助理，性格與擅長的工作跟 OpenClaw 不一樣；兩個可以分開裝、可以串起來分工。

這篇不比較到處被講的那個開源研究助理（網路上有人會把它當成 Hermes Agent 在介紹，那跟我們養的 Hermes 不是同一個，後面會講清楚怎麼分辨）。我們只看 OpenClaw 跟我們自己養的 Hermes：差在哪、怎麼選、要花多少。

一句話總結：差在哪

OpenClaw 像個能幫你跑雜事的助理；Think BIG 養的 Hermes 像個會幫你整理資料、想事情、寫東西的助理。一個動作派、一個思考派；裝在你電腦上、幫你做事是同一件事，做的事不同。要兩個都要也行，看你工作長怎樣。

四個角度的差別

1. 定位：動手做事 vs 想事情寫東西

OpenClaw 擅長的是「你給它一個動作，它跑完給你看」這類：固定流程、定期提醒、回訊息、整理檔案、串工具。你比較少跟它聊天，你比較常下指令給它。

Hermes 擅長的是「你想釐清一件事，它幫你整理出來」這類：長對話、文件改寫、研究型彙整、寫草稿、想辦法。你會跟它比較多對話，它的價值在你寫出東西的速度。

2. 記憶方式：動作脈絡 vs 對話脈絡

OpenClaw 的記憶偏向「這次任務做過什麼」：任務與狀態的連續性，每次任務結束會記住結果供下次參考。

Hermes 的記憶偏向「我們聊過什麼、結論是什麼」：跨對話、跨主題的累積，更像筆記本與思考線。

3. 技能生態：工作流技能 vs 文件與知識技能

OpenClaw 的技能圍繞在「讓它能動手做事」：通訊（LINE、Telegram）、檔案、排程、瀏覽器、客製腳本。

Hermes 的技能圍繞在「讓它想得更深、寫得更快」：長文摘要、研究彙整、知識庫比對、寫作風格模仿。

4. 適合場景：一個人日常 vs 多人協作

OpenClaw 對一個人、想讓生活雜事自動跑的人最對味。

Hermes 對一人公司、需要每天寫很多東西（企劃、文件、回信）、或想跟工作內容長期對話的人特別好用。

怎麼選？問自己三個問題

  1. 你比較常「叫 AI 做事」還是「跟 AI 討論事情」？前者 OpenClaw，後者 Hermes。
  2. 你的工作比較雜事多，還是寫東西多？雜事多 OpenClaw；寫東西多 Hermes。
  3. 你想要一個還是要兩個分工？一個就從 NT$999 那級開始；要兩個可以分開下單，也可以直接升級到雙助理 NT$15,000。
不確定的話：先裝 OpenClaw 跑一兩週，知道自己「還少什麼」，再決定要不要加 Hermes。多數人會從 OpenClaw 開始。

它跟「網路上的 Hermes Agent」是同一個嗎？不是

這段我們要特別講清楚，因為搜尋引擎上「Hermes Agent」最常見的結果，是另一個東西。

網路上最多人討論的「Hermes Agent」，指的是 Nous Research 開源的研究型助理，偏研究、長對話、模型本身。它的能力範圍、安裝方式、商業模式都跟 Think BIG 養的 Hermes 不一樣。Think BIG 養的 Hermes 是裝在你電腦上、可以動手做事、可以串 LINE 的工作型助理，定位完全不同。如果你看到「Hermes Agent 安裝」是教你跑開源模型、跑長研究，那是別的東西，跟這篇比的不一樣。

怎麼快速分辨：看到「GitHub clone、跑開源模型、研究用途」→ 那是別的；看到「裝在你電腦、串 LINE 跟 Telegram、做事」→ 那是 Think BIG 養的 Hermes 跟 OpenClaw。

常見問題 FAQ

Q：OpenClaw 跟 Hermes 是什麼關係？

OpenClaw 是個常駐在你電腦上、能把事做掉的 AI 助理；Think BIG 養的 Hermes 是同一類型的第二個助理，兩個可以單獨裝，也可以串起來當雙助理分工。先裝哪一個，看你工作場景。

Q：一個就夠還是兩個都要裝？

一個人、一個明確用途，裝一個就夠；想讓兩種不同風格的助理分工跑事、或想把工作流跟日常回訊息拆開，就兩個一起裝。

Q：裝兩個會不會很貴？

入門兩個方案各 NT$999，可分開下單；想把兩個助理串起來一起合作，可升級到雙助理方案 NT$15,000（含 30 天陪跑）。兩個分開的代裝費是 NT$999 + NT$999 共 NT$1,998。

Q：Think BIG 的 Hermes 跟網路上的 Hermes Agent 是同一個嗎？

不是。網路上最常見的「Hermes Agent」指 Nous Research 開源的研究型助理（偏研究、長對話、模型本身）；Think BIG 養的 Hermes 是裝在你電腦上、可以動手做事、可以串通訊軟體的工作型助理，定位完全不同。

Q：可以用年約方式同時養兩個嗎？

可以。年度旗艦 NT$38,000／年 就是兩個助理互通加全年維護的方案；尊榮年約 NT$32,000／年 是單系統年約。想清楚「要幾個助理」再看年約會比較不繞路。

結論：怎麼決定

如果你只是想把每天重複的雜事交給電腦跑——OpenClaw 先裝，跑一兩週，知道自己還少什麼。

如果你的工作常常要寫、要研究、要彙整——Hermes 先裝，從寫東西這件事開始加速。

如果你兩種都要、不想自己串——直接看雙助理 NT$15,000 或年度旗艦 NT$38,000。

如果還是不確定，先裝 NT$999 那一級就好。我們常看到裝了 OpenClaw 一個月之後再回頭加 Hermes，比一開始就買兩個還划算。
