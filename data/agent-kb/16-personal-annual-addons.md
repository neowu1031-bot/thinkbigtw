# 16｜個人年約、技能包、全 Agent 串接與售後
版本：2026-10-31
來源：/annual-pro/、/annual-flagship/、/full-agent/、/skill-pack/、/pricing/（加購區、客戶自理事項）。

個人年約（顧一整年，依需求報價，蝦皮選購，下單前先訪談確認架構）：
・尊榮年約（單 AI Agent）：OpenClaw 或 Hermes 擇一、全客製架構；一年維運陪跑（發現即修復＋48 小時故障修復）；每週例行維護＋依需求新增客製技能；Coding Agent 串接＋跨 Agent 協作會議室；全年無限次諮詢。
・年度旗艦（雙 AI Agent）：OpenClaw＋Hermes 同時部署、兩套互通；48 小時故障修復；每週維護＋多部門客製技能；每季 1 次 AI 戰略規劃（共 4 次）；Google Workspace、CRM／試算表／雲端硬碟整合；全年無限次諮詢。尊榮年約可補差額升級。
・兩檔都不打折；流程：訪談 → 遠端架設、確認可用 → 啟動年約；次年可選配續約（含每週維護＋48 小時故障修復）。

全 Agent 串接：OpenClaw 官方最新版＋60 組依職業量身開發的客製技能；串接你自己訂閱的 coding agent（Claude Code、Codex、Antigravity 等）；跨 Agent 協作會議室（建在你自己免費註冊的 Supabase 專案，資料與其他客戶隔離）＋結果推播到通訊軟體，手機下指令、電腦上的 Agent 接力完成；2 小時線上技術導覽＋安裝後 7 天技術諮詢。

技能包：給已裝 OpenClaw 或 Hermes 的人加裝客製技能（例如自動回信、報價單生成、排程提醒），10／20／40／120 組四種規格，依需求報價，先談需求再下單。多數技能採 0-Token 優先設計：能不呼叫 AI 模型就不呼叫，日常執行大多不增加模型費。120 組含 7 天技術諮詢，不含協作會議室與 coding agent 串接。

售後：系統健檢故障修復（給沒有年約的個人方案 1／2 客人）、OpenClaw 卸載服務，都在蝦皮。
客人自理：本地版模型運算不另收用量費；改搭雲端大模型時 API Key 由本人申請、依用量付費；LINE 只支援官方帳號；coding agent 訂閱自備；Supabase 自行免費註冊；以 AnyDesk／DeskIn 遠端安裝。
