# 13｜官網導覽：每一頁有什麼
版本：2026-10-31
來源：llms-full.txt（官網全站文字版，2026-10-31 與 main 同步）；/、/enterprise/、/enterprise/start/、/portfolio/、/experience/、/library/、/library/qa/、/library/news/、/guides/、/trust/、/en/。

官網 https://thinkbigtw.com 主要頁面：
・首頁：企業 AI Agent 導入介紹、AI 實戰體驗入口。首頁廣告的主持人是 AI 生成的虛擬人物，不是真人，有標示。
・企業導入 /enterprise/：三種方案範圍、地端版與雲端輔助版、採購常見問題。
・自助評估 /enterprise/start/：12 題問卷、約 3 分鐘，自動建議適合哪種方案；留聯絡資料後，1 個工作日內由真人聯繫，安排 30 分鐘遠端設備預檢與需求確認。問卷不收費；聯絡資料不送進 AI。
・AI 部門 /enterprise/departments/：各部門 AI Agent 的產物與權限。TB FRAME /enterprise/process/：四階段方法與導入工作表。RAG 說明 /enterprise/rag/：AI 依公司文件回答並附出處、資料流向與驗收。
・方案總覽 /pricing/：企業使用與個人使用兩扇門；個人方案 /pricing/personal/。
・作品集 /portfolio/：「AI Agent 實戰建置」（互動體驗＋建置簡報）、「ERP 進銷存互動 Demo」（親手新增商品、進貨、出貨）；更多作品準備中。
・AI 實戰體驗 /experience/：以 Think BIG 自己為示範公司，選一個部門和 AI 同事試做一件事；另有「AI 門市主管」用示範門市數據拆解營收。免登入，人名與數字都是虛構；對話會送到雲端 AI（Cloudflare Workers AI）處理，請勿輸入個資或機密；每天可問的題數有限。正式導入可改成地端。
・Library /library/：Think BIG NEWS（實際部署的第一手觀察與踩坑心得）與問答圖書館（一則一則的問答，每則附出處可查證；主題有企業資安、本地大模型、親子共讀與客製繪本等；合作品牌內容會清楚標示，品牌想做這類問答可透過 SEO＋GEO 月費代操代寫）。
・指南 /guides/：導入商評選、地端 AI 與資料主權、驗收框架、各家 AI Agent 比較；術語表 /guides/glossary/。
・資安與治理 /trust/。常見問題 /faq/、隱私權政策 /privacy.html、服務條款 /terms.html、聯絡 /contact/。
・英文版：/en/。社群：Instagram、Threads 為 @think_big_ai；YouTube 為 @think_big_ai_tw。

示範與作品一律用虛構或公司自己的資料；不公開客戶名稱、標誌、截圖或可推知身分的描述，也不安排客戶參觀。想看實際怎麼運作，可以看作品集、AI 實戰體驗，或預約 30 分鐘免費評估：https://thinkbigtw.com/enterprise/start/
