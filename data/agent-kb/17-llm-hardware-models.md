# 17｜本地大模型專業問答：硬體與模型怎麼挑
版本：2026-10-31
來源：內部《企業建置手冊》標準技術組合與預檢門檻（2026-09-27 查核）；本地模型建置必查清單（內部）。
來源：問答圖書館〈公司要跑本地大模型，需要什麼硬體？〉〈本地模型夠不夠聰明？〉〈本地大模型的缺點〉〈開源模型可以商用嗎？〉（2026-10-19／10-24 查證）。
來源：NVIDIA DGX Spark 官方規格 https://www.nvidia.com/en-us/products/workstations/dgx-spark/ （128GB 統一記憶體，官方寫可跑到 2,000 億參數模型，2026-10-31 查證）；Ollama 官方 FAQ https://docs.ollama.com/faq 。

先看顯示卡的顯示記憶體（VRAM），不是 CPU。模型整個放進顯示記憶體最快；放不下時部分改由 CPU 算，會慢很多。只用 CPU 也能跑，但多人使用太慢，不在標準範圍。

企業地端版標準規格（簽約前遠端預檢逐項確認）：
・24 小時開機的專用主機，Ubuntu 24.04 原生安裝（x86_64）。
・NVIDIA 顯示卡，顯示記憶體 24GB 以上（例如 RTX 3090／4090／5090 等級），驅動由經銷商或 IT 先裝好。
・系統記憶體 32GB 以上（建議 64GB）、SSD 可用 200GB 以上、有線網路、建議加 UPS。
適用前提：文件量在方案上限內（入門 30 份、標準與完整 100 份），驗收會測同時 3 個人提問；人數不限，但同時問的人越多越慢、會排隊。文件更多、多部門或同時提問多，評估時另估。
16GB 顯示卡、AMD 顯示卡、Mac、Windows（含 WSL2）目前不在地端標準範圍。Mac 本身能跑本地模型，但企業標準建置只驗證 Ubuntu＋NVIDIA；Windows 機器可重灌成 Ubuntu 專用機，或改雲端輔助版。已有設備先預檢，不預設要買新機。
DGX：標準方案不需要。DGX Spark 記憶體大（官方規格 128GB 統一記憶體），但不在目前已驗證的交付組合，有需要另案評估。

用哪個模型：地端標準採已驗證的固定組合，生成模型是 Qwen 系列約 270 億參數（27B）的中型模型，量化後約 18GB，可整個放進 24GB 顯示卡。B＝10 億參數；權重之外還要留空間給上下文和同時提問。
Llama、Mistral、Gemma、gpt-oss 等也是常見的開放權重模型。沒有「最好」的模型；換其他模型屬另案，先查該版本官方授權（能否商用、有無規模門檻），再用貴公司確認的情境測試題重新驗證。
模型來源與資安：模型在公司主機上執行，要管的是主機的連線。地端版對外不開入站埠，必要的出站連線（遠端維護、更新下載）逐項寫進資料路徑附件。資安政策要求特定模型來源，評估時提出。
跟雲端大模型比：公司設備跑得動的模型，能力通常不及最新雲端大模型，換來資料在公司設備內處理；夠不夠用以情境測試題實測為準。
