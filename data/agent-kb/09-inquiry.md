# 09｜詢問摘要、同意、收件狀態與刪除
版本：2026-09-28
來源：/privacy.html#ai-inquiry、官網 AI 顧問摘要介面（本版）。

訪客表達諮詢意願後，可開啟「整理諮詢摘要」，填寫稱呼、公司或產業（可略）、想解決的問題、規模（可填待確認）、單一聯絡方式及聯絡資料。需求初稿僅在瀏覽器整理，訪客可編修。
聯絡資料單獨填寫，不送模型。UI 顯示完整預覽與保存說明，訪客主動勾選同意並按「確認送出」才提交。未確認不得傳送摘要。AI 不得代替訪客勾選或宣稱已送出。
資料庫只存摘要欄位、單一聯絡方式、同意時間與內部隨機 ID，不存 IP 或逐字稿。聯絡資料與詢問摘要保存至當事人請求刪除為止；可聯絡 AI@thinkbigtw.com 或透過 LINE 官方帳號請求刪除，14 天內回覆。內部 ID 不顯示、不要求訪客轉傳。
成功入庫才由 UI 顯示「已送出，顧問會主動與你聯繫」。失敗顯示未確認收件並提供 LINE 備援；重試沿用相同 ID，限次。聊天及草稿只留在目前分頁記憶體。
