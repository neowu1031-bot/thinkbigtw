# 07｜個人價格、支援期、續約與排除費用
版本：2026-10-01
來源：/pricing/personal/（方案金額與服務條件母頁）、/skill-pack/。

以下數字只適用個人服務，不適用企業。
個人方案 1：人格版 AI 助理，NT$6,000 單次付清，OpenClaw 或 Hermes 擇一，可選討好型（溫暖支持，不盲目附和）或討伐型（直接犀利，不人身攻擊）人格，含完整個人技能包＋1 個客製小幫手、Coding Agent 串接 1–2 個、7 天技術諮詢，僅供個人使用，無年度維運承諾。若因我方技術問題無法完成安裝，全額退費。
個人方案 2a：雙 AI Agent 共存版（正式名稱「共存版」），NT$12,000，OpenClaw＋Hermes 兩套同時安裝、各自運作、各自記憶、人格組合自選，不含 MCP 記憶互通與跨 Agent 協作會議室，含標準個人技能包、7 天技術諮詢，無年度維運承諾。
個人方案 2b：雙 AI Agent（正式名稱「雙 AI Agent」，勿稱「協作版」），NT$15,000，OpenClaw＋Hermes 兩套同時安裝、MCP 記憶互通（兩個助理共享記憶）、含跨 Agent 協作會議室（此方案專屬，共存版和人格版均不含）、技能數依訪談、2 小時線上技術導覽＋安裝後 7 天技術諮詢，無年度維運承諾。
個人方案 3：單 AI Agent NT$32,000／年、雙 AI Agent NT$38,000／年。一年維運陪跑（發現即修復）、48 小時故障修復；次年續約 NT$30,000／年，含每週維護。兩檔皆不打折。
加購技能包：10／20／40 組 NT$1,000／2,000／3,000；120 組 NT$4,888，OpenClaw 或 Hermes 擇一，不含協作會議室及 coding agent 串接。先談需求再下單。
非年約客系統健檢故障修復：季 NT$9,800／半年 NT$15,000；年約客已含維運。OpenClaw 卸載服務 NT$500。
費用不含第三方模型用量費；API Key 自行申請，我方引導不代辦；coding agent 訂閱自備、Supabase 自行註冊。LINE 僅支援官方帳號 Messaging API，不支援個人帳號。
