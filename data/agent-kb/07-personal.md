## 常見問題
### 個人方案有哪些？
個人方案共兩階：AI 助理安裝 NT$6,000（討好型或討伐型人格任選，OpenClaw 或 Hermes 擇一，含個人技能＋1 個專屬小幫手，7 天售後諮詢，不含維護）；雙 AI Agent NT$15,000（OpenClaw＋Hermes MCP 互通，兩個 Agent 可各選人格，含協作會議室）；年約 NT$32,000／38,000，次年 NT$30,000／年。不含第三方模型用量費，完整範圍請見個人方案專區。

### 6,000 和 15,000 的差別？
6,000 是一個 AI Agent（OpenClaw 或 Hermes 擇一），選好人格後裝好就能用，不含維護。15,000 是兩個 AI Agent（OpenClaw＋Hermes）MCP 互通＋跨 Agent 協作會議室，兩個 Agent 可各選一種人格，技能數依訪談配置。

### OpenClaw 和 Hermes 的差別？
OpenClaw：動手快，第一天就能查資料、讀寫檔案、操作瀏覽器，適合「交代了就要馬上做完」的人。Hermes：越用越懂你，把做成功的方法記下來變成新技能，下次同類的事做得更快，適合想長期養一個助理的人。安裝時都可以選人格。

### 什麼是討好型／討伐型人格？
安裝 OpenClaw 或 Hermes 時可選其中一種人格：
- **討好型**：溫柔、支持、會鼓勵你、永遠站在你這邊。有護欄：不盲目附和，該提醒時會溫柔提醒。
- **討伐型**：毒舌直球，戳破拖延和藉口；遇到不合理的事，幫你想出有梗、有理的回話；會把事實一件件整理清楚。有護欄：不辱罵、不做人身攻擊、不歧視。
雙 AI Agent 方案（NT$15,000）可以兩個各選一種，例如一個討好型＋一個討伐型。

NT$999 入門方案已於 2026-09-29 停售。目前個人方案從 NT$6,000 起（人格版，含人格選擇、個人技能全套、1 個專屬小幫手）。已購入 999 方案的客戶不受影響，售後支援繼續有效。
