# 07｜個人方案：本地大模型 AI Agent 搭建
版本：2026-11-09
來源：/pricing/personal/（方案說明母頁）、/skill-pack/。

個人方案定義：把 AI 模型和 AI Agent 裝在客人自己的電腦上運算，再接到 LINE 官方帳號或 Telegram。可安裝：Apple M 系列 Mac、Windows／Linux＋NVIDIA 獨立顯卡、AMD Ryzen AI Max 統一記憶體機（條件與速度見第 22 章）。規格不夠改搭雲端大模型，同方案、同價格。
個人方案 1｜單 Agent 搭建（OpenClaw 或 Hermes 擇一；另有 OpenClaw＋60 組職業技能的「個人 AI 助理搭建」）：含本地大模型搭建、個人技能組＋1 個專屬小幫手、7 天技術諮詢；蝦皮賣場選購；不含維護；個人和企業都可以用在自己的工作上；多人共用、以公司資料建知識庫，或替第三方代裝、轉售，請選公司方案；若因我方技術問題無法安裝，全額退費。
個人方案 2｜雙 Agent：本地大模型、MCP 記憶互通、跨 Agent 協作會議室（此方案專屬）、遠端安裝＋教學影片＋安裝後 7 天技術諮詢；蝦皮賣場選購。雙 Agent 共存版請 LINE（https://lin.ee/n5KW430）洽詢。
個人方案 3｜尊榮年約（單）或旗艦年約（雙）：一年陪跑、48 小時故障修復、每週維護；次年續約另計。
加購技能包：10／20／40／120 組，給已搭建 AI Agent 的客人；先談需求再下單。
選配：已有 Claude Code 或 Codex 訂閱的人，可加串接成 Coding Agent（訂閱自備，只做串接設定）。
費用說明：本地版不另收模型用量費。改雲端大模型時 API Key 由本人申請（我方引導不代辦），依用量向模型廠商付費；問題和資料會送到模型廠商伺服器處理。Supabase 自行免費註冊；LINE 僅支援官方帳號 Messaging API。

## 常見問題

### 還要自己申請 API Key 嗎？
本地版不用，不另收模型用量費。改搭雲端版才需要你本人申請 API Key、依用量付費。

### 本地版跟雲端版差在哪？
本地版模型在電腦上運算，不另收費，但回覆較慢（16GB Mac 實測一題約 25–35 秒，規格越高越快）。雲端版回覆快，適合長文件大量資料，但需申請 API Key 並依用量付費。

### 我之前買的方案會受影響嗎？
不受影響，不用補費用，照原購買內容服務。

### OpenClaw 和 Hermes 差在哪？
OpenClaw：動手快、執行型，適合即時跑流程。Hermes：越用越懂你、學習型，把成功方法記下來。
