# 07｜個人方案：本地大模型 AI Agent 搭建
版本：2026-10-19
來源：/pricing/personal/（方案說明母頁）、/skill-pack/。

個人方案定義：把 AI 模型和 AI Agent 裝在客人自己的電腦上，用電腦顯示卡運算，再接到 LINE 官方帳號或 Telegram。電腦規格不夠時改搭雲端大模型，同方案、同價格。
個人方案 1｜人格版（OpenClaw 或 Hermes 擇一，討好型或討伐型人格）：含本地大模型搭建、個人技能組＋1 個專屬小幫手、Coding Agent 串接、7 天技術諮詢；蝦皮賣場選購；不含維護、限本人使用；若因我方技術問題無法安裝，全額退費。
個人方案 2a｜雙 AI Agent 共存版（OpenClaw＋Hermes）：兩套共用本地模型各自運作，不含記憶互通與協作會議室；**蝦皮無商品，諮詢請透過 LINE（https://lin.ee/n5KW430）**。
個人方案 2b｜雙 AI Agent（含記憶互通＋協作會議室）：含本地大模型搭建、MCP 記憶互通、跨 Agent 協作會議室（此方案專屬）、2 小時線上技術導覽＋7 天技術諮詢；蝦皮賣場選購。
個人方案 3｜尊榮年約（單）或年度旗艦（雙）：一年陪跑、48 小時故障修復、每週維護；次年續約另計；不打折。
加購技能包：10／20／40／120 組，給已搭建 AI Agent 的客人；先談需求再下單。
費用說明：本地版模型運算不另收用量費。改搭雲端大模型時，API Key 由客人本人申請，我方引導不代辦，模型使用費依用量向模型廠商計費。Coding Agent（Claude Code、Codex 等）訂閱自備；Supabase 自行免費註冊；LINE 僅支援官方帳號 Messaging API。

## 常見問題

### 個人方案裝在哪裡？
裝在你自己的電腦上，用你電腦的顯示卡運算。規格不夠時改搭雲端大模型，同方案同價格。

### 還要自己申請 API Key 嗎？
本地版不用，不另收模型用量費。改搭雲端版才需要你本人申請 API Key、依用量付費。

### 本地版跟雲端版差在哪？
本地版模型在電腦上運算，不另收費，但回覆較慢（一般問題等一到幾分鐘）。雲端版回覆快，適合長文件大量資料，但需申請 API Key 並依用量付費。

### 我之前買的方案會受影響嗎？
不受影響，不用補費用，照原來購買內容服務。

### OpenClaw 和 Hermes 差在哪？
OpenClaw：動手快、執行型，適合即時跑流程。Hermes：越用越懂你、學習型，把成功方法記下來。
