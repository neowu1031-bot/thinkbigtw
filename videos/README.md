## ⚙️ 影片規格建議

- **解析度**:1920×1080(1080p)或 1280×720(720p,檔案較小)
- **編碼**:H.264 / mp4
- **背景**:純白(#FFFFFF) — 我前端會用 blend mode 去白
- **檔案大小**:單檔 < 25MB(GitHub 網頁上傳限制)
- **角色方向**:依 prompt 嚴格遵守(法鬥從左、NEO 在右)
