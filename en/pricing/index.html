Think BIG (Think BIG Make it Real CO., LTD.) is an enterprise AI Agent deployment provider headquartered in Taiwan and serving clients worldwide. With TB FRAME, our four-phase deployment methodology (Assess, Build, Validate, Operate), we help companies run AI Agents on their own hardware, keep data inside the company, and provide one year of hands-on maintenance. We also offer personal AI assistant installation plans.

On-premises deployment does not mean every connection stays on the machine. If cloud models or external services are used, those requests still leave the device. When data must stay inside the company, local models, outbound restrictions and available features need to be confirmed first.

Which computer can run a local model?

Personal plans install the AI model and the AI Agent on your own computer. Apple M-series Macs, Windows (or Linux) with an NVIDIA GPU, and AMD Ryzen AI Max unified-memory machines can all be assessed. Only entries marked as tested are ones we have actually run; the rest are estimates, so please send a screenshot of your specs before ordering. If the specs fall short, we switch to a cloud model on the same plan.

DeviceMemoryWhat to expect
Apple M-series Mac (macOS 14 or later)16 GBMinimum, tested. Usable but slow: everyday Q&A, short text, simple tasks, about 25–35 seconds per question (tested on a Mac mini M4 with 16 GB). For multi-step work, images, long documents or coding, a cloud model is recommended.
24 GB or moreRecommended (estimate). Steadier than 16 GB and can hold a larger model.
32 GB or moreEstimate. Suited to Dual Agent or Hermes.
8 GB, or Intel MacUse a cloud model (8 GB was too slow in testing).
Windows (or Linux) with an NVIDIA GPU (Windows 10 22H2 or later)GPU 8 GB / system 16 GBMinimum (usable but slow).
GPU 12 GB or more / system 32 GBRecommended.
GPU 16 GB or more / system 32 GBSuited to Dual Agent or Hermes. With no discrete GPU, or under 8 GB of GPU memory, use a cloud model.
AMD Ryzen AI Max unified-memory machineRyzen AI Max+ 395, 64 GB (Windows)We have installed this setup: about 32–40 seconds per plain-chat question with a single Agent, and about 3–4 minutes per question when searching the web. Other AMD GPUs, AMD machines under 64 GB, and AMD on Linux are assessed case by case.

NVIDIA tiers are estimates; send a screenshot of your specs before ordering. Common requirements: at least 40 GB of free disk space (60 GB or more for machines with 64 GB or more memory that run a mid-size model), and a stable network on installation day because the model download is about 7–20 GB. Keep the computer on and awake. Timings come from a single machine; real speed depends on question length, number of skills and other programs running. The final decision between local and cloud rests on an engineer's review of your screenshots. With a cloud model, your questions and data are processed on the model provider's servers, and usage fees are paid from your own account.

Your responsibilities (all personal plans)

  • Local model: no API key or usage fees required. If switching to a cloud model, apply for your own API key (we guide you; we do not apply on your behalf); model usage fees are billed by the provider.
  • LINE: Official Accounts only (Messaging API); personal LINE accounts are not supported.
  • Coding agent subscriptions (Claude Code, Codex, etc.) are your own.
  • Register a free Supabase account yourself.
  • Installation: remote session via AnyDesk or DeskIn. If installation cannot be completed because of a technical issue on our side, you receive a full refund.
