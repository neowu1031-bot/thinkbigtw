THINK BIG

AI Implementation Glossary

From on-premises deployment and data sovereignty to scenario acceptance — consistent definitions for evaluating AI Agent deployment scope.

AI and Collaboration Deployment and Delivery Data and Governance Tools and Usage Costs

This glossary is organized around our deployment process, governance documentation, and personal plans — use it to align terms when evaluating services.

Further reading: TB FRAME (our four-stage deployment method: Assess, Build, Validate, Operate) deployment process, data governance, acceptance framework, personal plans.

AI and Collaboration

AI Agent

An AI assistant that executes workflows within approved data, tools, and operational scope; deliverables and significant actions still require review by a designated person.

In a Think BIG deployment, work is defined by approved knowledge, expected deliverables, and prohibited operations.

Agentic AI

The practice of using AI Agents to execute processes, use tools, and produce reviewable outcomes.

In a Think BIG deployment, we first confirm data, tools, and human decision boundaries before evaluating suitable workflows.

Human-in-the-loop

Having AI support work products and process execution under designated human approval and review control points.

In a Think BIG deployment, outbound sending, spending, and formal system changes require approval from a designated person.

Deployment and Delivery

TB FRAME

Think BIG's AI Agent deployment methodology, divided into four phases: Assess, Build, Validate, Operate.

In a Think BIG deployment, each phase has defined deliverables and review responsibilities.

TB READINESS (pre-deployment self-assessment: confirm process, data, and readiness conditions)

A six-question deployment readiness self-assessment. Answers are computed only in the browser — nothing is transmitted or stored. Results do not constitute certification or a formal consulting evaluation.

On the Think BIG website, you can use the self-assessment to organize pre-deployment prerequisites before confirming details with a consultant.

TB DELIVERY (build, test, and deliver AI workflows per confirmed scope)

An AI Agent deployment build service covering process inventory, data and permission design, AI Agent configuration, acceptance testing, and operational handover.

In a Think BIG deployment, build scope and acceptance responsibilities are confirmed before work begins.

TB CONTINUITY (one year of maintenance, issue tracking, and usage adjustments after deployment)

An annual AI Agent governance and operations service providing one year of continuity, issue tracking, maintenance checks, and change records within the agreed scope.

In a Think BIG deployment, the service contact, maintenance scope, and expansion handling are written into the agreement.

Scenario Acceptance

Verifying deliverable specifications, exception handling, and human approval mechanisms using normal, missing-data, service-interruption, and unauthorized scenarios.

In a Think BIG deployment, test records and outcomes are reviewed by a designated person.

Data and Governance

On-Premises Deployment

Deploying work data and execution environments on company-designated equipment. If external models or services are used, transmitted fields and authorizations must still be confirmed.

In a Think BIG deployment, equipment, models, and external connection scope are all confirmed together.

Data Sovereignty

The company confirms data sources, processing locations, access roles, and external transmission scope, while retaining authorization and decision-making responsibility.

In a Think BIG deployment, the data and permissions inventory must be traceable with clearly listed approval responsibilities.

Least Privilege

Opening data and operational scope only as required by the work, confirmed by a designated person.

In a Think BIG deployment, the fact that a tool is capable of an operation does not mean it is authorized by default.

Human Approval

Critical operations such as outbound sending, spending, and formal system changes are decided by a designated person before execution.

In a Think BIG deployment, acceptance also includes verifying that operations stop when not approved.

Auditability

Retaining source, operation, and verification records so that processes and conclusions can be re-traced.

In a Think BIG deployment, accountability is confirmed through data and permissions inventories, change records, and acceptance records.

Change Log

Before adjusting configurations or processes, record the reason, scope, responsible person, and rollback method.

In a Think BIG deployment, changes require prior approval, then validation with relevant scenarios to confirm impact.

Tools and Usage Costs

MCP

Model Context Protocol — an open protocol for connecting AI tools to data and functions. The actual accessible scope is still determined by account permissions and configuration.

In Think BIG services, MCP integrations still require verification of tools, accounts, and actual permissions.

Model Usage Fee

The cost paid to a model provider based on AI model usage. The local personal plan does not incur this separately; cloud-based usage is billed per use and is not included in the service fee.

In Think BIG personal services, the local plan does not incur model usage fees. When using cloud-based large models, usage fees are paid directly to the model provider based on actual use.

Zero-Token Priority

Preferring fixed rules or code — which require no model inference — to handle suitable tasks.

This design principle is used in the Think BIG personal skill package. The local plan incurs no model usage fees; cloud-based usage may still generate model usage fees depending on use.

RAG

Retrieval-Augmented Generation: first retrieving relevant knowledge, then providing it to the model as the basis for its response.

When evaluating enterprise knowledge Q&A, Think BIG first confirms data sources, authorization, and answer traceability. The actual architecture is confirmed per requirements. Learn more about RAG data preparation and acceptance.

Skill

Instructions and tool configurations that enable an AI Agent to execute specific tasks.

In Think BIG personal services, skill items and scope are confirmed based on the selected plan and an interview.

OpenClaw

An AI Agent platform that can be configured with skills and tools in a designated environment.

Think BIG personal starter services offer an OpenClaw installation option. Equipment and account requirements must be confirmed first.

Hermes Agent

An AI Agent tool for configuring AI assistants and workflows.

Think BIG personal plans offer Hermes installation and configuration options. Feature scope is confirmed per the corresponding plan page.
