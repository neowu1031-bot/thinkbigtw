When AI Searches Company Documents, Where Does the Data Go in Cloud vs. On-Premises Setups?

Think BIG Q&A Library  ·  2026-10-19   ·  中文

The short answer

On-premises: employees' questions, company documents, and the AI's answers are all processed on the company's own hardware. Cloud-assisted: the employee's question, plus the document passages the system retrieves, are sent to the model provider and retained for a period under the provider's rules (for example, up to 30 days by default for the OpenAI and Anthropic APIs). One more check: if the embedding step used for indexing also runs on a cloud service, document content is sent out in chunks when the index is built.

1. The four stages data passes through

The common way to let AI search company documents is RAG (retrieval-augmented generation): before answering, the AI retrieves relevant passages from company documents and writes the answer from them. The approach comes from Lewis et al. (2020). Data passes four stages:

Stage What happens On-premises Cloud-assisted
1. Indexing Documents are split and converted to vectors in a knowledge base On company hardware Depends: a local embedding model keeps it in-house; a cloud embedding API sends the passages out
2. Retrieval Relevant passages are found for the question On company hardware Usually on company hardware or a server under the company's account
3. Answering "Question + retrieved passages" go to the model Model on company hardware Question and passages go to the model provider
4. Logging Chat logs, system logs, backups Stored where the company designates The company keeps its own logs; the provider retains data under its own policy

Stage 3 is the key. The cloud-assisted version does not send the whole knowledge base, but every question sends the passages retrieved for it. More questions mean more document fragments leave the company.

2. How long providers retain data

Per official documentation (checked 2026-10-19):

  • OpenAI API: since March 1, 2023, API data is not used for training by default. Abuse monitoring logs, which may include prompts and responses, are retained up to 30 days by default. Eligible customers can apply for Zero Data Retention, subject to OpenAI's prior approval.
  • Anthropic API: inputs and outputs are deleted within 30 days of receipt or generation by default. Exceptions include customer-controlled storage (such as the Files API), separate agreements, Usage Policy enforcement, and legal requirements.

So the cloud-assisted version means two things: data leaves the company, and it stays on someone else's servers for a while. If a policy says a document must never leave the company, it belongs only in the on-premises knowledge base.

3. Five questions to ask before you start

  1. Where does embedding happen? A local model or a cloud API? With a cloud API, document content leaves when the index is built.
  2. Where is the answering model? Local or a cloud provider? Under whose account?
  3. Where are chat logs and system logs kept, and for how long? Who can see them?
  4. What other external services are connected? LINE, email, cloud storage: messages through any of these pass through that service.
  5. Which documents must never leave? List them and confirm they only go into the on-premises knowledge base.

If all five have clear answers, the data flow is understood. Any question without an answer is where to dig further.

FAQ

Q1: Does using a cloud model to search company documents send the whole knowledge base?
No, but each question sends the employee's question and the passages retrieved for it to the model provider. If the indexing step uses a cloud embedding API, document content is also sent in chunks when the index is built.
Q2: Does on-premises deployment mean no data ever leaves?
Not necessarily. On-premises decides where the model and documents sit. If the workflow connects to a cloud model, messaging app, or other external service, that part of the data goes out. Check the local model, outbound restrictions, logs, and backups.
Q3: How long do cloud model providers keep the data I send?
Per official documentation, OpenAI API abuse monitoring logs are kept up to 30 days by default; Anthropic API inputs and outputs are deleted within 30 days by default, with exceptions. Actual terms depend on your plan and contract.
Q4: What should we ask before letting AI search company documents?
Where embedding happens, where the answering model runs, where logs are kept and for how long, which external services are connected, and which documents must never leave the company.
