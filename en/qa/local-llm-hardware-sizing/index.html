What Hardware Does a Company Need to Run a Local LLM, and How Much GPU Memory?

Think BIG Q&A Library  ·  2026-10-19   ·  中文

The short answer

Start with GPU memory, not the CPU. The model file must fit entirely in GPU memory, with room left for context and the number of people using it at once. Going by download sizes in Ollama's official library, an 8B-class model is about 5.2GB, 14B about 9.3GB, and 32B about 20GB. OpenAI states that gpt-oss-20b can run within 16GB of memory, while gpt-oss-120b fits on a single 80GB GPU.

1. Why GPU memory comes first

To answer a question, a local model has to be loaded into memory. Whatever fits in GPU memory runs on the GPU; whatever does not is placed in system memory and computed by the CPU, which is noticeably slower.

Ollama's ollama ps shows the split directly. A PROCESSOR value of 100% GPU means the whole model is on the graphics card; a ratio such as 48%/52% CPU/GPU means only part of it fits (the example in Ollama's FAQ). So the order is: decide the model size, check whether GPU memory is enough, then look at everything else.

2. How much space common models need

Download sizes from Ollama's official library (default tags, checked 2026-10-19). File size roughly equals the memory needed to load the model; context needs additional memory on top.

  • Consumer graphics card example: the NVIDIA GeForce RTX 5090 has 32GB of GDDR7 memory, enough for every model above up to 32B.
  • Desktop AI system example: NVIDIA DGX Spark has 128GB of unified memory; NVIDIA states a single unit runs models up to 200 billion parameters.

3. Four steps to choose hardware

1. Decide the task, then the model. Answering from company documents, organizing data, and drafting replies usually work with mid-sized models. There is no need to start with a machine for the largest model. To judge whether a model is good enough, see "Is a local model smart enough?"

2. Size GPU memory from the model file, with headroom. Ollama's default context is 4,096 tokens. Letting the AI read more document passages at once means raising the context, which uses more memory.

3. Count concurrent users separately. Ollama's FAQ states that OLLAMA_NUM_PARALLEL sets how many requests each model handles at once, and required memory scales with parallel requests times context length. When memory runs short, new requests queue. Ten people asking at once need more memory than one.

4. Place and configure the machine properly. An AI Agent that must respond at any time needs a machine that stays on 24 hours. Ollama binds to 127.0.0.1 port 11434 by default; if you open it to the office network, use a firewall to allow only specific devices, and do not expose it to the internet.

FAQ

Q1: For a local LLM, does the CPU or the graphics card matter more?
Start with GPU memory. When the whole model fits, the GPU does the work; whatever does not fit goes to the CPU and slows things down noticeably. With Ollama, the PROCESSOR column in `ollama ps` shows the split.
Q2: What can run on 16GB of GPU memory?
By Ollama's official library sizes, 8B-class (about 5.2GB) and 14B-class (about 9.3GB) models fit. OpenAI also states that gpt-oss-20b runs within 16GB of memory. Leave room for context.
Q3: How much memory if many staff use it at once?
Calculate it separately. Ollama's FAQ states that required memory scales with the number of parallel requests times context length, and new requests queue when memory runs short.
Q4: Can the local model machine be exposed to the internet?
Not recommended. Ollama binds only to 127.0.0.1 by default. To let other office devices use it, open access to specific devices through a firewall rather than to the internet.
