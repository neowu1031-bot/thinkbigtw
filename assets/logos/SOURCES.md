### 外圍 AI Agent 的官方 MCP 文件

下列頁面已於 2026-09-27 讀取核對；產品的傳輸協定、設定與帳號權限各有不同。「共用」指完成相容設定與個別授權後取用同一 MCP 服務，不代表自動共用登入憑證或所有工具能力。

| 圖上 AI Agent | 官方 MCP 文件 | 確認範圍 |
| --- | --- | --- |
| OpenClaw | [Connect MCP servers](https://docs.openclaw.ai/tools/mcp) | 可連接外部 MCP 工具伺服器；支援 stdio、Streamable HTTP、SSE；仍受工具政策限制 |
| Hermes Agent | [MCP — Nous Research](https://hermes-agent.nousresearch.com/docs/user-guide/features/mcp) | 使用 `mcp_servers` 連接本機 stdio／遠端 HTTP 工具伺服器 |
| Claude（Claude Code） | [Connect Claude Code to tools via MCP](https://code.claude.com/docs/en/mcp) | Claude Code 透過 MCP 取用外部工具、資料庫與 API；此處未把 Messages API 文件當成 Managed Agent 的證據 |
| OpenAI Codex | [Model Context Protocol](https://developers.openai.com/codex/mcp/) | Codex CLI／IDE MCP 設定；官方目前重導至 [ChatGPT Learn](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) |
| ChatGPT | [ChatGPT Developer mode](https://developers.openai.com/api/docs/guides/developer-mode) | 網頁開發者模式的 MCP client；遠端 SSE／Streaming HTTP；需符合帳號／工作區權限 |
| Gemini CLI | [MCP servers with Gemini CLI](https://geminicli.com/docs/tools/mcp-server/) | 設定、探索與呼叫 MCP 伺服器工具 |
| Cursor | [Model Context Protocol (MCP)](https://cursor.com/docs/context/mcp) | 透過 MCP 連接外部工具與資料來源；以設定頁或 `mcp.json` 管理 |
| GitHub Copilot | [Extending GitHub Copilot Chat with MCP servers](https://docs.github.com/en/copilot/customizing-copilot/extending-copilot-chat-with-mcp) | Copilot Chat 使用 MCP；組織／企業方案需允許 MCP 政策 |

「你的 Agent ＋」是可擴充的空節點，不是另宣稱一項產品已支援。
工具列表示可透過已建置的 MCP server／API adapter 取用；並非宣稱所有列出的服務都提供官方 MCP server。LINE 指官方帳號 Messaging API。

### MCP 沿革與治理的官方依據

- [Anthropic 2024-11-25 開源公告](https://www.anthropic.com/news/model-context-protocol)：提出並開源 MCP，用以連接 AI 與工具、資料來源。
- [MCP 官方 2025-12-09 公告](https://blog.modelcontextprotocol.io/posts/2025-12-09-mcp-joins-agentic-ai-foundation/)：Anthropic 將 MCP 捐贈給 Linux Foundation 旗下的 AAIF；MCP 保有技術方向與日常運作自主權，維護者架構不變。
- [modelcontextprotocol.io — Governance](https://modelcontextprotocol.io/community/governance)：由 lead maintainers、core maintainers、maintainers 等角色及社群參與治理。

頁面所說「權限與稽核集中在 MCP 這層管」是串接系統的建置方式；MCP 協議本身不自動提供完整稽核、權限控管或人工核准。
